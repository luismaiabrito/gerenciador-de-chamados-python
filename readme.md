# Gerencia&Chama

Gerencia&Chama é um projeto de estudo desenvolvido em Python para simular um sistema de gerenciamento de chamados.

O projeto está sendo desenvolvido passo a passo para praticar lógica de programação, estruturas de controle, funções, autenticação e, futuramente, armazenamento de dados e banco de dados.

## Funcionalidades atuais

* Login de usuário e administrador
* Diferenciação entre usuário comum e administrador
* Menu específico para cada tipo de usuário
* Validação das opções inseridas
* Retorno ao login após sair do menu
* Opção de encerrar o programa

## Próximos passos

* Implementar abertura de chamados
* Armazenar chamados
* Consultar chamados
* Alterar status dos chamados
* Cadastro de usuários
* Listagem de usuários
* Implementar hash seguro para senhas
* Persistência dos dados
* Banco de dados
* Melhorar a organização do projeto

## Tecnologias

* Python 3.14
* Git
* GitHub

## Segurança

As credenciais presentes na versão atual são fictícias e existem exclusivamente para fins educacionais.

A autenticação atual ainda não representa uma implementação adequada para produção. Uma das próximas etapas será substituir as senhas em texto puro por armazenamento seguro utilizando hashing de senhas.

O projeto também será desenvolvido considerando boas práticas de privacidade e proteção de dados.
